# Task Logs

Use this folder for task-local checkpoints when work has multiple steps or needs
handoff. When a plan already records the needed state, link to it instead of
creating a second narrative. A separate handoff records only new resume state.

Recommended filename format:

```text
YYYY-MM-DD-short-task-name.md
```

Link shared goals and verification once. Capture changed files, unresolved findings,
verified revision, external effects, and the next action. Add context or command
details only when needed to resume. Start from `docs/agent/TASK_LOG_TEMPLATE.md`.
