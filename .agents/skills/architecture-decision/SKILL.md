# Architecture Decision

1. State the decision, constraints, non-goals, and compatibility requirements.
2. Compare two or three practical options against those constraints.
3. Recommend the simplest option that satisfies the requirements.
4. Identify migration cost, reversibility, operational risk, and follow-up work.
5. Create or update an ADR when the decision changes durable project behavior.

Return the decision, options considered, recommendation, tradeoffs, and ADR status. Prefer the existing architecture unless a concrete constraint requires change.
